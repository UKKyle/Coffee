# Coffee Storefront — Phase 1

Working storefront prototype for the coffee venture.

## Stack
- React
- Vite
- Cloudflare Vite plugin
- Cloudflare Workers / Static Assets

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Direct Cloudflare deploy
```bash
npm run deploy
```

## Cloudflare Git deployment
Connect this repository in Cloudflare and use the repository root. The project is configured through `wrangler.jsonc` and `vite.config.ts`.

Working brand name: **Dose Standard** (placeholder only).
